# Quine 🌀

A simple **Quine** written in JavaScript and designed to run in the browser.

A Quine is a program that outputs its own source code without reading the source file or using external input containing the source code.

## 🛠️ Built With

* HTML
* JavaScript

## 🚀 Run

No installation or dependencies are required.

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open `index.html` in your browser.

3. Open the browser's **Developer Tools → Console** to see the output.

## 🧠 What is a Quine?

A Quine is a self-reproducing program — a program that outputs its own source code.

The key idea is that the program must reproduce its source **without reading the source file itself**.
